# Domain docs

Galaxy Frog uses a single domain context across the browser and backend.

## Read before exploring

- Read the relevant packet and verification records in [PLANS.md](../../PLANS.md).
- Read the [workspace redesign plan](../WORKSPACE_REDESIGN_PLAN.md) for product and system behavior.
  For frontend journeys and evidence presentation, read the [workspace design](../WORKSPACE_DESIGN.md).
- Read the relevant accepted decisions in the shared [ADR directory](../adr/).
- Read the root `GLOSSARY.md` when it exists. Until then, use the established terms in the
  plans, ADRs, and implementation.

Use the established vocabulary in tickets, code, and tests. Flag conflicts with accepted ADRs in
proposals. Add a single root `GLOSSARY.md` when domain modeling identifies a durable terminology gap.
