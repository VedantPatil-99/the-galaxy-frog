# Triage labels

Map each engineering skill role to the matching GitHub issue label.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting maintainer review |
| `needs-info` | `needs-info` | Awaiting details needed to proceed |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Declined |
